    Príprava — pred prednáškou¶

    Pripravte si svoj počítač podľa nasledujúcich krokov.

    1 — Získajte IBMid¶

    IBM Bob vyžaduje IBMid. IBMid je bezplatné — vytvorte si ho na ibm.com/account/reg (trvá to ~2 minúty). Ak už IBMid máte, tento krok preskočte.

    2 — Aktivujte bezplatnú skúšobnú verziu¶

    Zaregistrujte sa na skúšobnú verziu IBM Bob (50 Bobcoinov na 30 dní) pomocou rovnakého IBMid, ktoré ste vytvorili v kroku 1: bob.ibm.com/trial

    3 — Nainštalujte IBM Bob¶

    IBM Bob je samostatné IDE — nie rozšírenie pre VS Code. Stiahnite si ho z bob.ibm.com/download a pri prvom spustení sa prihláste pomocou svojho IBMid.

    Stiahnite si inštalátor pre váš operačný systém z bob.ibm.com/download.

    Spustite inštalátor, postupujte podľa sprievodcu a pri prvom spustení sa prihláste pomocou IBMid.

    Preferujete prácu v termináli? Nainštalujte si Bob Shell:

    macOS / Linux 

    curl -fsSL https://bob.ibm.com/download/bobshell.sh | bash
    Windows (PowerShell) 
    powershell -ep Bypass 'irm -Uri "https://bob.ibm.com/download/bobshell.ps1" | iex'
    Po výzve sa autentifikujte na bob.ibm.com/login.

    4 — Ďalšie požiadavky¶

    • Nainštalovaný Node.js 20 LTS (alebo novší LTS), Python 3.11+ a Git (ak ich ešte nemáte, pozrite nižšie)
    • Naklonovaný repozitár z GitHubu (pozrite posledný krok nižšie)

    Ako otvoriť terminál¶

    Stlačte kláves Win, napíšte PowerShell a stlačte Enter. (Alebo kliknite pravým tlačidlom na tlačidlo Štart a vyberte Terminal / Windows PowerShell.)

    Stlačte Cmd + Space, napíšte Terminal a stlačte Enter. (Alebo otvorte Finder → Applications → Utilities → Terminal.)

    Stlačte Ctrl + Alt + T (funguje vo väčšine distribúcií) alebo vyhľadajte Terminal v ponuke aplikácií.

    Môžete použiť aj terminál priamo v IBM Bob: stlačte Ctrl+` (alebo v menu vyberte Terminal → New Terminal).

    Inštalácia Node.js, Pythonu a Gitu (preskočte, čo už máte)¶

    Najprv skontrolujte, čo už máte nainštalované — v termináli spustite:

    node --version    # potrebná verzia v20 alebo novšia
python --version  # potrebná verzia 3.11 alebo novšia
git --version

    node --version    # potrebná verzia v20 alebo novšia
python3 --version # potrebná verzia 3.11 alebo novšia
git --version

    Ako vyhodnotiť výsledok z terminálu:

    Nástroj Vyžadovaná verzia 🟢 OK 🔴 Chyba
    Node.js v20+ Vypíše napr. v20.18.0 Hláška „is not recognized…“ (macOS/Linux: „command not found“)
    Python v3.11+ Vypíše napr. Python 3.12.4 Hláška „is not recognized…“ alebo sa otvorí MS Store — potrebná inštalácia
    Git verzia 2.x Vypíše napr. git version 2.45… Hláška „is not recognized…“ (macOS/Linux: „command not found“)

    Ak príkaz nebol nájdený alebo je verzia príliš stará, nainštalujte ho:

    Otvorte PowerShell a použite winget (súčasť Windows 10/11):

    winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.12 -e

    Potom zatvorte a znovu otvorte terminál, aby sa načítala nová premenná PATH.

    Nefunguje winget? Stiahnite si inštalátory z nodejs.org, python.org (zaškrtnite Add python.exe to PATH) a git-scm.com.

    Ak nemáte Homebrew, nainštalujte ho a potom spustite:

    brew install git node python@3.12

    Alternatívne si stiahnite inštalátory z nodejs.org, python.org a git-scm.com.

    sudo apt update
sudo apt install -y git python3 python3-pip python3-venv curl

    Node.js v predvolených repozitároch apt býva príliš starý, preto ho nainštalujte cez nvm:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    Reštartujte terminál a potom spustite:

    nvm install --lts

    Ak je python3 --version staršia ako 3.11, nainštalujte novšiu (napr. sudo apt install python3.12 python3.12-venv) alebo postupujte podľa dokumentácie vašej distribúcie.

    Overenie inštalácie¶

    Po inštalácii zatvorte terminál a otvorte nový, potom znova skontrolujte, že je všetko nainštalované:

    node --version    # v20 alebo novšia
python --version  # 3.11 alebo novšia
git --version

    node --version    # v20 alebo novšia
python3 --version # 3.11 alebo novšia
git --version

    Každý príkaz by mal vypísať číslo verzie. Ak sa zobrazí „command not found“ alebo „is not recognized“, inštalácia sa nedokončila alebo ste terminál nereštartovali — zopakujte inštaláciu príslušného nástroja.

    Ak príkaz python stále otvára Microsoft Store (Windows)

    Windows obsahuje prednastavené „aliasy“, ktoré blokujú vlastnú inštaláciu Pythonu. Vypnite ich takto:

    1. Stlačte kláves Win a napíšte Spravovať aliasy spúšťania aplikácií (alebo Manage app execution aliases).
    2. V zozname nájdite položky Inštalátor aplikácií (python.exe) a python3.exe.
    3. Prepnite ich vypínač na pozíciu Vypnuté (Off).

    4. V PowerShelli spustite preinštalovanie natvrdo:

      winget install --force Python.Python.3.12

    Potom zatvorte terminál, otvorte nový a znova spustite python --version.

    Naklonovanie repozitára¶

    Naklonujte repozitár do priečinka Documents:

    V PowerShelli:

    cd $HOME\Documents
git clone --recurse-submodules https://github.com/stu-fei-bob-lecture/bob-workshop-stu-fei.git

    Projekt bude v C:\Users\<vaše-meno>\Documents\bob-workshop-stu-fei.

    cd ~/Documents
git clone --recurse-submodules https://github.com/stu-fei-bob-lecture/bob-workshop-stu-fei.git

    Projekt bude v /Users/<vaše-meno>/Documents/bob-workshop-stu-fei.

    cd ~/Documents
git clone --recurse-submodules https://github.com/stu-fei-bob-lecture/bob-workshop-stu-fei.git

    Projekt bude v /home/<vaše-meno>/Documents/bob-workshop-stu-fei. Ak priečinok Documents nemáte, najprv ho vytvorte príkazom mkdir -p ~/Documents.

    Kontrolný zoznam pred prednáškou¶

    Zaškrtni všetky kroky, ktoré už máš úspešne hotové.

    • 1. Zaregistrovaný IBMid účet
      Máš vytvorený študentský/osobný IBM účet.
    • 2. Aktivované bezplatné kredity (50 Bobcoinov)
      Na adrese bob.ibm.com/trial máš aktivovaný bezplatný skúšobný balík.
    • 3. Nainštalované prostredie IBM Bob IDE
      Aplikácia IBM Bob je nainštalovaná a prihlásená k tvojmu účtu.
    • 4. Overené: Node.js v20+ funguje
      Príkaz node --version vypisuje verziu v20 alebo novšiu.
    • 5. Overené: Python 3.11+ funguje
      Príkaz python3 --version (vo Windows python --version) vypisuje verziu 3.11 alebo novšiu.
    • 6. Overené: Git funguje
      Príkaz git --version vypisuje číslo verzie Gitu.
    • 7. Projekt naklonovaný a pripravený
      Repozitár je naklonovaný v priečinku Documents.
